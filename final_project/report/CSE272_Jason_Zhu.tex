%%  ABSTRACT

\begin{abstract}
We present an implementation and extension of West's~\cite{west2024stylized} framework for stylized rendering as a function of expectation within the La~Jolla physically-based renderer. We begin with a suite of 2D image-space NPR post-processing effects as a baseline (\textbf{Pipeline~1}), then implement a real-time unlit renderer inspired by the Sokpop Collective's Deer Hunter~II aesthetic (\textbf{Pipeline~2}). Building on these foundations, we develop a deterministic cel-shading integrator (\textbf{Pipeline~3}) and culminate in a \textbf{multi-style Monte~Carlo showcase} (\textbf{Pipeline~4}) featuring per-object dispatch of three distinct style functions---cel-shading, tie-dye cosine mapping, and artistic color palette (ACP)---demonstrated in a custom open-air \emph{Sculpture Garden} scene with animated lighting. Our results demonstrate that stylization applied to the \emph{expectation} of Monte~Carlo transport yields aesthetically coherent effects with physically grounded illumination, including global illumination, soft shadows, and color bleeding. Source code and scenes available at \url{https://github.com/zhuyuezx/lajolla_public}
\end{abstract}

\section{Introduction}
\label{sec:intro}

Non-photorealistic rendering (NPR) has a long history in computer graphics, from Gooch shading~\cite{gooch1998non} and toon/cel-shading to more recent painterly and hatching styles. However, most traditional NPR techniques operate in a simplified shading model (e.g.\ a single directional light, no indirect illumination) or are applied as image-space post-processes that are blind to 3D light transport.

West~\cite{west2024stylized} proposes an elegant alternative: apply a \emph{non-linear style function} $g_\theta$ to the Monte~Carlo \emph{expectation} of physically based radiance at each pixel. Because the style function operates on the converged estimate $\langle I \rangle$ rather than individual samples, the resulting image inherits full global illumination (GI) effects—soft shadows, color bleeding, caustics—while exhibiting the desired artistic look.

In this project, we implement and extend this framework within the La~Jolla renderer~\cite{li2018differentiable} across four pipelines:

\begin{enumerate}
    \item \textbf{Pipeline~1} (Post-Processing NPR): 2D image-space effects including Obra~Dinn--style 1-bit ordered dithering, toon/cel quantization, and Kuwahara-based painterly rendering.
    \item \textbf{Pipeline~2} (Deer Hunter~II Viewer): A real-time unlit flat-albedo renderer with cast ground shadows and linear distance fog, built on Embree~4 and SDL2.
    \item \textbf{Pipeline~3} (Deterministic Cel-Shading): A single-directional-light cel-shading integrator with hard $\mathbf{N} \cdot \mathbf{L}$ shadow threshold and $k$-sample Monte~Carlo transition.
    \item \textbf{Pipeline~4} (Multi-Style Showcase): Per-object dispatch of three style functions (cel, tie-dye, ACP) in a custom \emph{Sculpture Garden} scene with a sweeping area light.
\end{enumerate}

Our primary contributions are: (a)~a practical implementation of West's stylization framework in La~Jolla, (b)~a per-object style dispatch mechanism enabling heterogeneous styles in a single render, and (c)~a custom open-air scene with animated lighting that demonstrates the viability of applying physically based illumination alongside stylistic color transformations.

\section{Related Work}
\label{sec:related}

\paragraph{Traditional NPR.}
Gooch et al.~\cite{gooch1998non} introduced a warm-to-cool shading model that maps $\mathbf{N} \cdot \mathbf{L}$ to a color ramp, providing shape cues without photorealism. Lake et al.~\cite{lake2000stylized} surveyed cartoon-style rendering, including silhouette extraction and quantized shading. These methods typically use a single light source and ignore indirect illumination.

\paragraph{Stylized path tracing.}
West~\cite{west2024stylized} formalizes the idea of applying a style function $g_\theta$ to the \emph{expected} exitant radiance at each visible surface point. The key insight is that the non-linear function should be applied \emph{after} averaging multiple Monte~Carlo samples, preserving the convergence properties of the estimator while introducing stylistic non-linearity. This differs from naively stylizing each sample independently, which produces noisy results that do not converge to the desired style.

\paragraph{Artistic color palettes.}
Color mapping and palette-based rendering have been explored in the context of image stylization~\cite{reinhard2001color}. West~\cite{west2024stylized} demonstrates two such mappings: a per-channel cosine ``tie-dye'' effect and a luminance-based Affects the Color on a Path trace (ACP)~\cite{doi2021global} ramp, both of which we implement in Pipeline~4.

\paragraph{Image-space post-processing NPR.}
A long-standing alternative to integrated NPR is to apply stylistic effects directly to a finished image.
Ordered dithering using Bayer matrices~\cite{floyd1976adaptive} converts a greyscale image to a binary pattern that simulates tone gradations, and was famously exploited by Pope's \emph{Return of the Obra Dinn}~\cite{obradinn2018} to achieve a striking 1-bit aesthetic.
Saito and Takahashi~\cite{saito1990comprehensible} introduced G-buffer--based outline extraction via depth and normal discontinuity detection, enabling clean silhouette rendering from a rasterized frame.
For painterly effects, Kuwahara et al.~\cite{kuwahara1976processing} proposed the anisotropic smoothing filter that replaces each pixel with the mean of its lowest-variance neighbor quadrant, producing blocky oil-paint strokes.
Litwinowicz~\cite{litwinowicz1997processing} extended this by overlaying oriented brush strokes aligned to image gradients, achieving impressionist-style videos.
Our Pipeline~1 (Section~\ref{sec:postproc}) implements all of these techniques as a 2D post-processing baseline, motivating the move to 3D-integrated stylization in Pipelines~3--4.

\paragraph{Low-poly and indie NPR aesthetics.}
A distinct strand of applied NPR has emerged in independent game development, where resource constraints motivate deliberate stylization as an aesthetic choice rather than an approximation.
The Sokpop Collective~\cite{sokpop2019deerhunter} exemplifies this approach in \emph{Deer Hunter~II}: low-polygon geometry is rendered with unlit flat albedo, binary ground shadows, and linear distance fog to produce a cohesive, immediately recognizable aesthetic.
This \emph{unlit rendering} paradigm---which deliberately foregoes physically based illumination in favor of artistic coherence---differs fundamentally from the Monte~Carlo stylization approach of West~\cite{west2024stylized}, and serves as a practical reference point for Pipeline~2 of our system.

\section{Method}
\label{sec:method}

\subsection{Background: Monte Carlo Rendering}
\label{sec:mc}

In physically based rendering, the color of each pixel is the integral of the measurement function over the pixel's area and the light transport paths. The rendering equation~\cite{kajiya1986rendering} defines exitant radiance $L_o$ at a surface point $\mathbf{x}$ in direction $\omega_o$ as:
\begin{equation}
    L_o(\mathbf{x}, \omega_o) = L_e(\mathbf{x}, \omega_o) + \int_{\mathcal{H}^2} f_s(\mathbf{x}, \omega_i, \omega_o)\, L_i(\mathbf{x}, \omega_i)\, |\cos\theta_i|\, \mathrm{d}\omega_i
    \label{eq:rendering}
\end{equation}
where $L_e$ is emission, $f_s$ is the BSDF, and the integral is over the hemisphere $\mathcal{H}^2$. Monte~Carlo path tracing estimates this integral by averaging $N$ random samples:
\begin{equation}
    \langle I \rangle = \frac{1}{N} \sum_{j=1}^{N} \frac{f_s \cdot L_i \cdot |\cos\theta_i|}{p(\omega_j)}
    \label{eq:mc_estimate}
\end{equation}


\subsection{Stylized Rendering Framework}
\label{sec:framework}

Following West~\cite{west2024stylized}, we define stylized rendering as the application of a non-linear style function $g_\theta$ to the expected radiance at each visible surface point. For a camera ray hitting surface point $\mathbf{x}$ with material albedo $\rho$, the stylized pixel color is:
\begin{equation}
    C_{\text{styled}} = g_\theta\!\bigl(\rho,\; \langle I \rangle_k\bigr)
    \label{eq:stylized}
\end{equation}
where $\langle I \rangle_k$ is the $k$-sample Monte~Carlo estimate of the physical radiance at $\mathbf{x}$. The key property is that $g_\theta$ is applied to the \emph{average} of $k$ inner samples, not to individual samples.

\paragraph{Inner trace.} Each of the $k$ inner samples is a full path trace from the first camera-hit vertex, using next-event estimation (NEE) with MIS weighting and Russian roulette for termination:
\begin{equation}
    \langle I \rangle_k = \frac{1}{k} \sum_{s=1}^{k} I_s, \qquad I_s = \sum_{b=0}^{B} T_b \cdot \bigl(w_1 \cdot C_{\text{NEE}}^{(b)} + w_2 \cdot C_{\text{BSDF}}^{(b)}\bigr)
    \label{eq:inner_trace}
\end{equation}
where $T_b$ is the path throughput at bounce $b$, $w_1, w_2$ are MIS weights, and $B$ is the path length (controlled by Russian roulette).


\subsection{Style Functions $g_\theta$}
\label{sec:style_functions}

We implement three style functions, each corresponding to a different visual effect from West~\cite{west2024stylized}.

\subsubsection{Cel-Shading (Pipelines 3--4)}
\label{sec:cel}

A hard-threshold quantization of luminance into lit and shadow bands:
\begin{equation}
    g_{\text{cel}}(\rho, \langle I \rangle) = 
    \begin{cases}
        \rho \cdot \mathbf{c}_{\text{light\_tint}} + \rho \cdot \mathbf{c}_{\text{ambient}} & \text{if } \text{lum}(\langle I \rangle) \geq \tau \\
        \rho \cdot \mathbf{c}_{\text{shadow\_tint}} + \rho \cdot \mathbf{c}_{\text{ambient}} & \text{otherwise}
    \end{cases}
    \label{eq:cel}
\end{equation}
where $\tau$ is the cel threshold (\texttt{cel\_threshold}), $\mathbf{c}_{\text{light\_tint}}$ and $\mathbf{c}_{\text{shadow\_tint}}$ are the per-XML light and shadow tint colors (\texttt{cel\_light\_tint}, \texttt{cel\_shadow\_tint}), and $\text{lum}(\cdot)$ computes the luminance of a color vector.

\paragraph{Mollification effect.} At low $k$, variance in $\langle I \rangle$ causes pixels near $\tau$ to stochastically flip between lit and shadow, producing a soft, anti-aliased boundary. At high $k$, the estimate converges and the boundary becomes sharp. This is the super-linear convergence property described in West~\cite{west2024stylized} \S4.4.

\subsubsection{Tie-Dye Cosine Effect (Pipeline 4)}
\label{sec:tiedye}

A psychedelic color mapping using per-channel cosine waves (West~\cite{west2024stylized}, Fig.~11):
\begin{equation}
    g_{\text{tiedye}}(\langle I \rangle)_c = \bigl|\cos\!\bigl(\nu_c \cdot \langle I \rangle_c + \phi_c\bigr)\bigr|, \qquad c \in \{r, g, b\}
    \label{eq:tiedye}
\end{equation}
where $\nu_c$ and $\phi_c$ are the per-channel frequency and phase parameters. Because the cosine operates on the physical radiance, the resulting color pattern is modulated by global illumination—shadows, reflections, and color bleeding all produce different hues.

\subsubsection{Affects the Color on a Path trace / ACP (Pipeline 4)}
\label{sec:acp}

A luminance-to-color-ramp mapping (introduced by Doi et al.~\cite{doi2021global}, and adapted by West~\cite{west2024stylized}, Fig.~7):
\begin{equation}
    g_{\text{acp}}(\langle I \rangle) = \text{lerp}\!\bigl(\mathbf{c}_{\text{dark}},\; \mathbf{c}_{\text{bright}},\; \text{clamp}\bigl(\text{lum}(\langle I \rangle), 0, 1\bigr)\bigr)
    \label{eq:acp}
\end{equation}
This maps all pixels to a two-stop gradient, creating a limited-palette illustration effect. Our implementation uses $\mathbf{c}_{\text{dark}} = (0.06, 0.02, 0.18)$ (deep indigo) and $\mathbf{c}_{\text{bright}} = (1.0, 0.50, 0.15)$ (sunset orange).


\subsection{Per-Object Style Dispatch}
\label{sec:dispatch}

Rather than applying a single $g_\theta$ to all objects, we assign each shape a style via three separate ID lists parsed from the scene XML:

\begin{equation}
    \text{style}(\texttt{shape\_id}) = 
    \begin{cases}
        \text{CEL}    & \text{if } \texttt{shape\_id} \in \mathcal{S}_{\text{cel}} \\
        \text{TIEDYE} & \text{if } \texttt{shape\_id} \in \mathcal{S}_{\text{tiedye}} \\
        \text{ACP}    & \text{if } \texttt{shape\_id} \in \mathcal{S}_{\text{acp}} \\
        \text{PBR}    & \text{otherwise}
    \end{cases}
    \label{eq:dispatch}
\end{equation}

Non-target objects skip the expensive $k$-sample inner loop entirely, using a single-sample PBR estimate instead, yielding approximately $k\!\times$ speedup for those pixels.


\subsection{Temporal Crossfade}
\label{sec:crossfade}

For animated transitions, we introduce a parameter $t \in [0, 1]$ that blends between the physical PBR estimate and the stylized output:
\begin{equation}
    C_{\text{final}} = (1 - t) \cdot \langle I \rangle_k + t \cdot g_\theta(\rho, \langle I \rangle_k)
    \label{eq:crossfade}
\end{equation}
At $t = 0$ the image is fully photorealistic; at $t = 1$ it is fully stylized. Intermediate values produce a smooth blend.

\section{Implementation}
\label{sec:implementation}

\subsection{Renderer Architecture}

All pipelines are implemented within the La~Jolla physically-based renderer~\cite{li2018differentiable}, a C++ path tracer with Embree-based ray-scene intersection. The key modified/added source files are:

\begin{itemize}
    \item \texttt{stylized\_pt\_integrator.h}: Core integrator with inner trace, style functions, per-object dispatch, and temporal crossfade.
    \item \texttt{npr\_integrator.h}: Deterministic cel-shading integrator (Pipeline~3) with AOV output.
    \item \texttt{scene.h}: Extended \texttt{RenderOptions} struct with per-style ID lists and style parameters.
    \item \texttt{parse\_scene.cpp}: XML parsing for \texttt{cel\_ids}, \texttt{tiedye\_ids}, \texttt{acp\_ids}, and associated parameters.
\end{itemize}

\paragraph{Post-processing baseline (Pipeline~1).}
\label{sec:postproc}
Before implementing the 3D-integrated pipelines, we developed a suite of 2D NPR post-processing techniques as a baseline. These operate on finished images and serve as a point of comparison: (1)~Bayer ordered dithering in the style of \emph{Return of the Obra Dinn}~\cite{obradinn2018,floyd1976adaptive}, converting images to a two-color palette; (2)~screen-space toon/cel quantization that snaps luminance into $B$ discrete bands; (3)~Kuwahara-based painterly rendering~\cite{kuwahara1976processing} with optional Litwinowicz-style~\cite{litwinowicz1997processing} oriented brush strokes; and (4)~Sobel outline post-processing~\cite{saito1990comprehensible} using G-buffer--based 4-connected neighbor comparison on depth, normal, and object-ID AOV buffers.

\subsection{Deer Hunter~II Viewer (Pipeline~2)}

Pipeline~2 is a standalone real-time viewer built with Embree~4 and SDL2, reproducing the aesthetic of the Sokpop Collective's \emph{Deer Hunter~II}~\cite{sokpop2019deerhunter}. The scene is fully procedural: a savanna with low-poly trees, ponds with reeds, rocks, deer, crows, and an animated player character. Rendering uses unlit flat albedo with binary cast ground shadows and linear distance fog fading to a warm sky color.

\subsection{Monte Carlo Stylization (Pipelines 3--4)}

Pipeline~3 uses a deterministic single-directional-light integrator with hard $\mathbf{N} \cdot \mathbf{L}$ cel-shading (Eq.~\ref{eq:cel}), and extends to $k$-sample Monte~Carlo estimates with temporal crossfade (Eq.~\ref{eq:crossfade}). Pipeline~4 adds per-object style dispatch (Eq.~\ref{eq:dispatch}) of three simultaneous style functions in the Sculpture Garden scene (Section~\ref{sec:scene}).

\subsection{Sculpture Garden Scene}
\label{sec:scene}

To demonstrate the multi-style system beyond the Cornell Box, we designed a custom open-air scene with procedurally generated OBJ meshes: a 60$\times$60 ground plane, three pedestal variants, a 32-sided cylindrical column, four spheres at various heights, and a large overhead area light positioned above the camera frustum.

Each shape is assigned a style: golden pedestals and sky-blue/pearl spheres receive \textbf{cel-shading}, the emerald column and lavender orb receive \textbf{tie-dye}, and terracotta/coral/slate objects receive \textbf{ACP}. The camera is fixed while the area light sweeps in a semicircular arc:
\begin{equation}
    \mathbf{p}_{\text{light}}(i) = \begin{pmatrix} -R\cos(\pi i / (N-1)) \\ y_{\min} + (y_{\max} - y_{\min})\sin(\pi i / (N-1)) \\ z_0 \end{pmatrix}
    \label{eq:light_sweep}
\end{equation}
where $R$ is the sweep radius, $y_{\min}$/$y_{\max}$ define the height range, and $N = 60$ frames.

Pipeline~1 runs in Python as an offline post-process. Pipeline~2 is real-time ($>$50~fps) due to its simple unlit evaluation. Pipeline~3 scales linearly with $k$. Pipeline~4 uses higher $k$ (256) and SPP (16) for quality renders; non-target objects remain cheap (1-sample PBR fallback).

\section{Discussion and Limitations}
\label{sec:discussion}

\subsection{Performance vs.~Visual Trade-offs}

West~\cite{west2024stylized} notes that style functions can be parameterized by object ID, making per-object stylization a natural extension of the framework.
Our contribution in this regard is primarily a performance one: we leverage the per-object parameterization to aggressively cull the $k$-sample inner trace for non-target geometry, falling back to a single-sample PBR evaluation for all other shapes.
This yields an asymptotic cost bounded to $\mathcal{O}(k)$ per styled pixel, circumventing the $\mathcal{O}(k^d)$ exponential overhead that would arise from recursive application of $g_\theta$ at each bounce $d$.

This choice imposes a corresponding visual limitation: indirect light paths encountering a styled surface are not themselves stylized.
For example, a stylized object reflected in a planar mirror would appear in standard PBR rather than in cel-shading, because the mirror bounce sees the surface as a non-first-hit vertex and uses the 1-sample fallback.
In practice, however, this first-hit restriction produces natural visual cohesion: stylized objects interact with the surrounding PBR environment as if they were physical, casting accurate color bleed and receiving correct indirect illumination, without the combinatorial sampling cost of recursive stylization.
For the animated sequences in Section~\ref{sec:results}, this trade-off makes 60-frame renders tractable on a single desktop CPU.

\subsection{Global Illumination and Energy Conservation}

Non-linear style functions fundamentally break physical energy conservation.
Cel-shading (Eq.~\ref{eq:cel}) injects ambient energy regardless of incident illumination; tie-dye (Eq.~\ref{eq:tiedye}) maps radiance to arbitrary cosine values that may exceed the incident energy; and ACP (Eq.~\ref{eq:acp}) maps all pixels to a fixed color ramp, discarding physical luminance relationships.

Because our pipeline computes genuine global illumination in the inner traces, styled objects act as de-facto emitters within the scene: GI-correct color bleeding from a cel-shaded object tints the surrounding diffuse geometry with the object's stylized hue rather than its physical albedo.
This is aesthetically pleasing in moderate scenes, but West~\cite{west2024stylized} notes a structural danger: if energy-increasing styles are applied recursively across all bounces, the path integral can geometrically diverge, producing runaway brightness.
Our first-hit-only restriction acts as a natural safeguard against this divergence, since indirect paths never accumulate additional stylized energy additions beyond the first camera vertex.

\subsection{Estimator Variance and Mollification}

Our cel-shading implementation uses the \emph{biased direct application} estimator: the discontinuous step function $g_{\text{cel}}$ (Eq.~\ref{eq:cel}) is applied directly to the finite-sample inner estimate $\langle I \rangle_k$.
Because $\langle I \rangle_k$ has residual variance $\sigma^2 / k$, pixels whose true radiance $I^*$ lies near the threshold $\tau$ stochastically classify as lit or shadowed, producing a blurred boundary instead of a sharp step---the \emph{mollification} effect.
The mollification width scales as $\sim\!\sigma / \sqrt{k}$, meaning that suppressing it purely by increasing $k$ is computationally expensive.
Importantly, this estimator is \emph{biased}: $\mathbb{E}[g_\theta(\langle I \rangle_k)] \neq g_\theta(\mathbb{E}[\langle I \rangle_k])$ when $g_\theta$ is non-linear, and the bias does not vanish at any finite $k$.

The ACP style function (Eq.~\ref{eq:acp}) suffers comparatively little from this artifact.
Being a linear interpolation, its curvature is identically zero, so variance in $\langle I \rangle_k$ produces only gradual color drift rather than stochastic binary flipping.
This makes ACP a more suitable default style for animated sequences where temporal coherence is important.

\section{Future Work}
\label{sec:future}

\subsection{Low-Discrepancy Sampling}

Our current inner-trace loop draws $k$ independent samples using a PCG pseudo-random number generator, resulting in sample clumping and a variance of $\mathcal{O}(1/k)$.
Replacing this with a stratified quasi-Monte~Carlo sampler---for example, a scrambled Halton or Sobol sequence with per-pixel Cranley--Patterson rotation---would reduce the discrepancy bound to $D_N^* = \mathcal{O}((\log N)^s / N)$, lowering the baseline variance $\sigma^2$ of the inner estimate without increasing $k$.
Since the mollification width is proportional to $\sigma / \sqrt{k}$, halving $\sigma$ through better sampling is equivalent in boundary sharpness to quadrupling $k$, at no additional rendering cost.
The \texttt{HaltonSampler} class implementing this strategy is available in \texttt{final\_project/stylized\_pt\_integrator.h}.

\subsection{Polynomial Approximation Estimators}

West~\cite{west2024stylized} (\S3.3) describes a class of estimators that replace the non-linear style function $g_\theta$ with a finite-degree polynomial approximation $\tilde{g}_m$ fitted in a Chebyshev basis.
For the cel-shading step function, which approximates a Heaviside discontinuity, the polynomial estimator satisfies:
\begin{equation}
    \mathbb{E}\bigl[\tilde{g}_m\bigl(\langle I \rangle_k\bigr)\bigr] = \tilde{g}_m\bigl(\mathbb{E}[\langle I \rangle_k]\bigr) + \mathcal{O}\!\left(\frac{\sigma^{2m}}{k^m}\right)
    \label{eq:cheby_bias}
\end{equation}
so the bias decays polynomially in $m$ rather than persisting at a fixed level as with direct application.
Implementing this estimator requires precomputing the Chebyshev coefficients of $g_{\text{cel}}$ and evaluating the polynomial at render time via the Clenshaw recurrence, a modest $\mathcal{O}(m)$ per-pixel overhead.
A degree-20 prototype (\texttt{eval\_cheby\_step} and \texttt{stylized\_apply\_cel\_chebyshev} in \texttt{final\_project/stylized\_pt\_integrator.h}) has been implemented; systematic evaluation of its bias-variance trade-off against direct application at matched $k$ is left as future work.

\subsection{Differentiable Stylized Rendering}

A longer-term direction is to integrate this stylized path tracer into a differentiable rendering framework such as Slang-D or Mitsuba~3~\cite{li2018differentiable}.
The core computational challenge is computing derivatives of the recursive, non-linear expectation functions in West's algorithm: the gradient of the stylized output with respect to scene parameters must propagate through both the style function $g_\theta$ and the inner Monte~Carlo estimator $\langle I \rangle_k$.
Differentiation through the inner-estimate requires either reparameterized path-space Monte~Carlo or dedicated edge-sampling procedures for visibility discontinuities, neither of which is trivially compatible with per-object style dispatch.
Nevertheless, a differentiable extension would allow artists to optimize stylization parameters---cel thresholds, ACP color ramps, tie-dye frequencies---directly from reference images or perceptual loss functions, removing the need for manual parameter tuning.

%%  8. CONCLUSION
%% ═══════════════════════════════════════════════════════════════
\section{Conclusion}
\label{sec:conclusion}

We have implemented and extended West's framework for stylized rendering as a function of expectation within the La~Jolla renderer~\cite{li2018differentiable}. Our four-pipeline progression---from image-space post-processing (Pipeline~1) through a real-time Deer Hunter~II viewer (Pipeline~2) and deterministic cel-shading (Pipeline~3) to Monte~Carlo multi-style dispatch (Pipeline~4)---demonstrates that applying non-linear style functions to physically based radiance estimates yields aesthetically coherent results with correct global illumination. The per-object dispatch mechanism bounds computational overhead to $\mathcal{O}(k)$ per styled pixel and makes animated sequences practical, while the multi-style Sculpture Garden scene demonstrates the flexibility of the approach for heterogeneous stylization. Code and scenes are available at \url{https://github.com/zhuyuezx/lajolla_public}.

\section{Integrator Pseudocode}
\label{app:pseudocode}

\begin{algorithm}[h]
\caption{Stylized Path Tracing with Per-Object Dispatch (Pipeline~4)}
\label{alg:stylized_pt}
\begin{algorithmic}[1]
\REQUIRE Scene $\mathcal{S}$, ray $(o, d)$, params $\theta$
\STATE $\mathbf{x} \leftarrow \text{Intersect}(\mathcal{S}, o, d)$
\IF{miss}
    \RETURN $\mathbf{c}_{\text{bg}}$
\ENDIF
\STATE $\text{style} \leftarrow \text{GetStyleForShape}(\texttt{shape\_id}(\mathbf{x}))$ \hfill {\footnotesize // Eq.~\ref{eq:dispatch}}
\IF{$\text{style} = \text{PBR}$}
    \RETURN $\text{InnerTrace}(\mathbf{x}, 1)$ \hfill {\footnotesize // single sample, fast}
\ENDIF
\STATE $\langle I \rangle \leftarrow \frac{1}{k}\sum_{s=1}^{k} \text{InnerTrace}(\mathbf{x}, s)$ \hfill {\footnotesize // Eq.~\ref{eq:inner_trace}}
\STATE $C_{\text{styled}} \leftarrow g_\theta(\rho(\mathbf{x}),\, \langle I \rangle)$ \hfill {\footnotesize // Eq.~\ref{eq:cel}/\ref{eq:tiedye}/\ref{eq:acp}}
\RETURN $(1 - t) \cdot \langle I \rangle + t \cdot C_{\text{styled}}$ \hfill {\footnotesize // Eq.~\ref{eq:crossfade}}
\end{algorithmic}
\end{algorithm}
